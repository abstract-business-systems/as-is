# Assessing Determinism - as-is

## Purpose
Identify evidence-supported deterministic improvements while preserving intentional generative behavior.

## Design

The skill compares repeated behavior and inputs, isolates nondeterministic sources, and recommends only changes supported by observed variance rather than preference. It is an analysis sibling under the Skills catalog: it classifies steps and quantifies variance, but it does not implement fixes itself — it recommends retention, a bounded backlog item, or an explicitly authorized task. The skill establishes fit only and grants no tools or authority; it does not change behavior directly or authorize parent-level work.
