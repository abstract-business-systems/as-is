# Writing code - as-is

## Purpose
Create or substantially implement code from a bounded requirement.

## Design

The skill translates an authorized requirement into new or substantially generated implementation and hands the diff to focused testing and validation rather than claiming completion. It is the implementation counterpart to `applying-bounded-edits`, which owns surgical changes to existing artifacts, and it hands off to testing and validation skills such as `writing-tests` and `validating-changes`. The skill establishes fit only: it grants no tools or authority, and it does not cover surgical changes to existing artifacts.
