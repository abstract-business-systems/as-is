# Writing tests - as-is

## Purpose
Add or update focused coverage for a stated behavior.

## Design

The skill maps each test to an acceptance condition or risk, chooses the smallest relevant test level, and documents residual gaps instead of implying full coverage. It receives changed behavior from implementation skills such as `writing-code` and feeds evidence to validation skills such as `validating-changes`. The skill establishes fit only: it grants no tools or authority and does not run or authorize the broader task lifecycle.
