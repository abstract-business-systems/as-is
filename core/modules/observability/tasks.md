# Task

## Requirement
Implement `core/modules/observability:emitted-path-privacy-enforcement` at the observability tracer boundary only. Preserve internal filesystem operands and telemetry-failure isolation, but prevent direct or indirect filesystem paths from crossing any serialized local JSONL or OTLP event field. Add provider-free focused fixtures for direct, nested, absolute, repository-relative, component-derived, configured-directory, worktree, session, task-record, and log path values, while preserving explicitly approved tracer-owned scalar metadata and the validated opaque session ID. Do not change launcher, recovery, evidence-tool, host-adapter, task-control, process, or generic privacy authority behavior.

## Plan
1. Read the observability component record, backlog item, `docs/execution-contract.md`, design principles, tracer implementation/tests, and named privacy constraints.
2. Obtain a read-only expert plan review before editing.
3. Define one tracer-local emission projection used by both local JSONL serialization and the exported `otlpPayload` seam. Treat runtime input as `unknown` at the projection boundary and record this exact policy: event names use the explicit allowlist of `parent`, `child`, `failed`, `reference`, `worker.result`, `subprocess.launch`, `worker.lifecycle`, `subprocess.exit`, `subprocess.handoff`, `first`, `second`, `json-authority`, `control-plane.delegate`, `session.lifecycle`, `delegation.lifecycle`, `child-wait`, and `component-build`; known current supervisor names `task-record.checkpoint`, `supervisor.watchdog`, `component-build.worker`, `component-build.completed`, `recovery.scheduled`, and `recovery.escalated` are deliberately projected to the bounded literal `unknown` until separately admitted, and every other name also becomes `unknown`. Trace/span/parent IDs use JSON-safe opaque correlation text only: non-empty ASCII characters excluding slash, backslash, NUL, URL scheme, and whitespace, at most 128 characters; unsafe values become deterministic `unknown` and are not required to satisfy OTLP hexadecimal semantics because the existing OTLP formatter remains responsible for bounded padding/truncation. Timestamps are host-generated or match strict RFC3339 syntax with a timezone (`YYYY-MM-DD[T]HH:MM:SS(.digits)?(Z|[+-]HH:MM)`); invalid caller timestamps are replaced by the host timestamp, and the projected timestamp feeds both JSONL and OTLP nanoseconds. `durationMs` retains only finite non-negative numbers at most 86,400,000; malformed, negative, or excessive values are omitted. Attribute keys use an exact allowlist: `outcome`, `bounded`, `workerRole`, `outcomeClass`, `handoffClass`, `launcherMode`, `reason`, `duration_ms`, `as_is.outcome`, `as_is.run_id`, `as_is.component_path`, `as_is.task_revision`, `as_is.role`, and `parentJobId`; all other keys, including path-bearing keys, are omitted. Allowlisted keys retain booleans and finite numbers where applicable, but string values are retained only for `outcome` (`success`/`failure`), `bounded` (`true`/`false` only if represented as a string by a legacy caller), `workerRole` (`as-is`, `component-builder`, `expert`, `execution-advisor`, or `worker`), `outcomeClass` (`success`, `failure`, or `budget-stopped`), `handoffClass` (`committed`, `pending-parent-integration`, `not-committed`, or `no-separate-integration`), `launcherMode` (`detach` or `blocking`), `reason` (`error`, `cancelled`, `unavailable`, `rejected`, or `budget-stopped`), and `as_is.outcome` (`success`, `failure`, or `unspecified`); `as_is.run_id`, `as_is.component_path`, `as_is.task_revision`, `as_is.role`, and `parentJobId` never retain strings because their current path/identity payloads are not proven safe. Omit undefined, null, arrays, objects, functions, symbols, bigints, and non-finite values, and do not rewrite, redact, normalize, hash, or infer path-like values into a generic sanitizer.
4. Ensure every serialized caller-controlled string field is safe, including `traceId`, `spanId`, `parentSpanId`, `name`, `timestamp`, attribute keys, and session references. Preserve a session reference only when its session ID satisfies the same ASCII opaque-token grammar above; invalid, path-like, store-bearing, or payload-bearing session references are omitted while the otherwise-safe event still emits. Resolve the known supervisor fallback where `request.component` can become `traceId` by mapping the unsafe correlation value to deterministic `unknown` at the tracer boundary without changing supervisor ownership. No filesystem path or replacement path-like value is emitted.
5. Add focused provider-free local-file and OTLP payload fixtures asserting complete serialized payload absence for unique direct, nested, absolute, repository-relative, component-derived, configured-directory, worktree, session, task-record, and log path tokens. Cover path-bearing attribute keys, current non-allowlisted supervisor event names projecting to `unknown`, malformed runtime values through casts, invalid/negative/non-finite/excessive durations, strict-invalid timestamps, invalid session references, preserved approved metadata, append-only output, disabled backend, unsafe-only input, caller-input immutability, failing file/OTLP transport isolation, and existing lifecycle hierarchy behavior.
5. Run focused tracer/lifecycle tests, no-bundle type/build validation, task/content/backlog validation, whitespace checks, diagnostics, and final expert review.
6. Record bounded residual risk: launcher/recovery, evidence-tool, and future host-adapter emission surfaces remain separate enforcement tasks.
