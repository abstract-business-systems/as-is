## Flow assignments

### Coding/application

```text
Terra custom plan/advice profile
→ Human Review of the exact frozen plan
→ separate kick-off and task admission
→ Luna custom implementation profile
→ deterministic validation
→ Terra custom non-independent result review
→ risk-triggered independent review when required
```

No Sol or Kimi coding/application plan review is required by the accepted coding/application flow. Terra's result review must disclose plan authorship and implementation advice and is non-independent.

### Agents/skills

```text
Sol custom plan/advice profile
→ external Kimi review of the same exact frozen plan
→ Human Review of that exact packet

→ deterministic validation
→ Sol custom non-independent result review
→ risk-triggered independent review when required
```

Kimi review is advisory and cannot approve, launch, implement, integrate, adopt, or close work. Sol's result review is non-independent because Sol authors and advises the plan.
