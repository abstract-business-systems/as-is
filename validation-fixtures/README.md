This directory is the navigation entry point for retained current validation,
dogfood, and recovery evidence. Each child `as-is.md` remains authoritative for
its own current record. Historical task recovery uses Git history and the
repository [change log](../change-log.md), not archive-folder snapshots. This
README is not a task backlog or second authority.

- [OpenCode mediation dogfood](opencode-mediation-dogfood/README.md) and
  [Increment 5 dogfood](increment-5-dogfood/README.md) — completed historical
  validation fixtures.
- [Increment 6 recovery fixture](increment-6-recovery-fixture/as-is.md) —
  completed recovery evidence.
- Increment 5 cost observability — historical blocked/no-retry evidence is
  summarized in [change-log.md](../change-log.md); no retry is authorized.

The grouping is non-runtime and preserves each current child's status and
lineage. Refer to the child records for authoritative results and next actions;
refer to Git and the change log for retired historical work.
